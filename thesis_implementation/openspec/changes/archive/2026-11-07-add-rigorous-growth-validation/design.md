# Design

Chronological inclusive cycle intervals are assigned only when fully within train, validation, or test; boundary-crossing cycles are excluded. Temporal test and validation use fields present in training. Held-out fields are excluded from all fitting and calibration; their future cycles form a distinct unseen-field test, not necessarily a geographically separated block. Missing inputs remain missing. The cycle adapter uses the archive's precomputed segmentation, which can use future data: this is a retrospective experiment, not proof of online detection.

An NDVI-only adapter avoids inconsistent changes to derived bands. The two fitted baseline implementations are global phase-wise robust median/MAD and past-window Isolation Forest. Fit and imputation use training exclusively; a global validation point-score quantile fixes the threshold. Score originals and modified copies, evaluate point AP/ROC on 50:50 paired modified bins and simple contiguous modified-run recall and within-event delay; report field counts and original alert fraction. Point AP is not operational prevalence precision. Labels describe perturbations only. Missing bins split events and very small datasets can yield few/no eligible events. Do not apply point adjustment or present the simple overlap event metric as affiliation precision. Peak is a one-observation modification and delay is a local shifted observation, not a full biological model.

Interfaces: `prepare_growth_validation.py` converts pre-segmented Zarr; `validate_growth.py` consumes NPZ `X,start_dates,end_dates,field_ids`. Models expose `fit(X)` and `score(X)` returning N×K scores; inputs must not have test-fitted preprocessing. Scenario grid and splits should be locked before final evaluation. Output contains protocol and scenario details. Additional mechanism and model adapters are future work.


Additional implementations include trailing-window One-Class SVM, freshly trained masked GRU/Transformer adapters, centroid blocks and buffer, field-bootstrap event recall, seed-repeat runner, and descriptive historical-weather/neighbor analysis. SSL scoring observes the rest of the cycle, and centroid distances are not polygon distances. Inputs and outputs are documented in `docs/growth_validation.md`.

`field_phase_mad` additionally fits a shrunk field-specific phase offset only from training data, with global fallback for unseen fields. The weather exporter copies only actually available time samples; shared regional time series require explicit opt-in and are not represented as independent local measurements.

Causal-prefix GRU and Transformer models use only the current masked target and earlier bins; fixed-horizon binning accepts independently known, dated start anchors and avoids smoothing. Retrospective segmentation remains non-causal. Affiliation code is vendored under MIT and computed separately within each contiguous finite-score segment; RSS is process-wide sampled memory, not exact incremental peak. Feature subset and random-encoder arms enable bounded ablations, not JEPA/Mamba claims.
