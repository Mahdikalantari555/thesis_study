# یافته ۲ — فنولوژی و چرخه‌ها

## روش

- هموارسازی Whittaker-Eilers روی سری نامنظم (λ tuned).
- تشخیص برداشت = کف NDVI با prominence کافی، قبلش پلاتوی بالا و بعدش صعود.
- چرخه = فاصلهٔ دو برداشت متوالی؛ چرخهٔ اول/آخر censored.
- محور اصلی: days-since-harvest (dsh)، bin ۱۵ روزه.

## نتایج

- ۱۷۰۴ چرخهٔ کامل (non-censored) از ۴۹۰ مزرعه.
- هر مزرعه به‌طور متوسط ~۳.۵ چرخهٔ کامل.
- stratumها: plant/ratoon × block group → ۷ stratum.

## یافتهٔ کلیدی

segmentation harvest-driven روی دادهٔ واقعی نیشکر جواب داد و چرخه‌های قابل استفاده برای baseline تولید شد.
این پاسخ مستقیم به سؤال فرعی «همسان‌سازی فاز فنولوژیک بین‌ساله» در ارائه است.
