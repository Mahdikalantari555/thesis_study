# یافته ۴ — ارزیابی و تزریق مصنوعی

## معیارها

- AUC-PR و recall در نرخ هشدار ثابت (۵٪ چرخه‌ها).
- تأخیر تشخیص (تعداد bin از آغاز تزریق تا اولین هشدار).
- Spearman با proxyها (ETa, CWSI, yield).

## نتایج (Run B با باندهای خام)

- ۱۵۰۰ چرخهٔ امتیازدهی‌شده، ۵۸۶ چرخهٔ دارای run (anomaly).
- mean_burden ≈ ۰.۰۶۳.
- synthetic recall @5% ≈ ۰.۰۱۰ (پایین — نشان می‌دهد baseline آماری به‌تنهایی حساسیت کمی دارد).
- mean detection delay ≈ ۱۱ bins (~۱۶۵ روز) — تأخیر زیاد، نشان می‌دهد baseline کند است.

## یافتهٔ کلیدی

- baseline آماری phase-aware (B1) یک کف مقایسهٔ قابل دفاع است، اما حساسیت و سرعت تشخیص آن محدود است.
- این توجیه علمی برای ورود SSL (G2) است: اگر SSL با CI معنادار از B1 بهتر نباشد، باید نقش آن به embedding/retrieval محدود شود.
- این دقیقاً gate G2 در طرح است.
