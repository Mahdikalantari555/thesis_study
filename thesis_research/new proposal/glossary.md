# Glossary — Key Terms (Persian / English)

| English | Persian | Definition |
|---------|---------|------------|
| Crop Water Stress Index (CWSI) | شاخص تنش آبی محصول | A thermal-based index measuring canopy water status via stomatal conductance |
| Electrical Conductivity (ECe) | هدایت الکتریکی عصاره اشباع | Standard measure of soil salinity in saturated paste |
| Leaf Area Index (LAI) | شاخص سطح برگ | Total one-sided leaf area per unit ground area |
| Self-Supervised Learning (SSL) | آموزش خودمحور | Learning representations from unlabeled data via pretext tasks |
| Satellite Image Time Series (SITS) | سری زمانی تصاویر ماهواره‌ای | Sequential satellite images of the same area over time |
| Foundation Model (FM) | مدل پایه | Large pre-trained model adaptable to downstream tasks |
| Explainable AI (XAI) | هوش مصنوعی قابل توضیح | Methods to interpret ML model predictions |
| Mamba / State-Space Model (SSM) | مدل فضای حالت | Architecture for efficient long-sequence modeling |
| Random Forest (RF) | جنگل تصادفی | Ensemble ML method using decision trees |
| Barlow Twins | بارلو توئینز | SSL method reducing cross-correlation between augmented views |
| Grad-CAM | کام دانش‌آموز (Grad-CAM) | Gradient-based class activation mapping for visual explanation |
| SHAP | شاپ (SHAP) | Shapley Additive Explanations for feature attribution |
| Partial Dependence Plot (PDP) | نمودار وابستگی جزئی | Visualizing effect of a feature on model prediction |
| Leave-One-Year-Out | خروج یک سال | Cross-validation holding out an entire year |
| Equifinality | برهم‌کنندگی | Same observable outcome from different causes |
| Mixed Stress | تنش مخلوط | Combined water + salinity stress (interactive, not additive) |
