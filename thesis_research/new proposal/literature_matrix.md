# Literature Matrix — New Proposal (20 Key Resources)

**Purpose:** Re-organized literature matrix for the proposal *"Crop Stress Detection in Sugarcane Fields Using Satellite Image Time Series"*. Rows are drawn from the canonical corpus (matrix IDs 01–78 in `Thesis_Vault/Literature-Matrix.md`). Selected ≤20 resources most relevant to the proposal's four sub-questions:

1. What was the exact problem each paper addressed?
2. Did it detect stress directly, or only monitor vegetation status?
3. Did it use single-date or time-series data?
4. What was its unit of analysis — pixel, field parcel, or farm/field?
5. Where did labels and validation data come from?
6. How was it evaluated, and what were its limitations?

**Citation style:** APA 7th Edition.
