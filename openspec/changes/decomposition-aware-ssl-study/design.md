## Context

`io/stats_zarr.py` exposes QA-derived field medians; `monitor/inputs.py` bins detected cycles for the deployed study and is not an acquisition-level input. `models/gru_ae.py` provides a causal GRU whose head cannot see the current token, but its existing loss reduces across channels before applying a token mask. Reuse the architecture, not that loss or a frozen cycle checkpoint. `scripts/stage_conditioned_anomaly.py` pools contemporaneous data across fields and relies on completed cycle lengths; it is not a causal per-field reference. Keep all three paths unchanged.

## Goals / Non-Goals

Compare feature and independent-score hypotheses in the same field/date cohort. Do not re-ingest pixels, promote a model, change shipped artifacts, run the reserved final test, or claim causal stress diagnosis. This is a same-field temporal development study, not a new-farm generalization experiment.

## Decisions

1. **Source and split.** Read pre-aggregated, polygon-contained zonal medians from `stats.zarr`, validate names and QC, and derive NDVI/EVI/NDMI from those medians (not medians of pixel indices). Use blue/green/red/NIR/SWIR1/SWIR2 for the bands arm; keep thermal out to reduce direct indicator circularity. Use the hash-verified frozen manifest as written, select admitted rows before reading values, and assert both field and date admission. Defaults: training before 2021, calibration in 2021, evaluation in 2022–23 (before the frozen cutoff). In each phase log actual scope, observation coverage and split hash. Smoke is explicit and simulated; never a real-data fallback.
2. **Decomposition.** Fit one series per field and variable. STL uses 15-day bins, period 24, median-of-observations bins and only bounded interior linear fills (at most three empty bins). Long gaps split fit segments; early or unsupported segments remain absent. Harmonic regression uses actual acquisition days with linear trend and two annual harmonics. At acquisition dates retain the *original* observed raw value and compute `R = X - T - S`. Store STL pre-fit grid states and observed acquisition masks. The causal estimator fits from observations strictly before a fixed 60-day refresh boundary and extrapolates from the last supported STL trend/seasonal cycle (bounded horizon); harmonic uses a trailing four-year fit. The retrospective estimator uses allowed history through each partition end and never mixes evaluation into training/calibration. It is an offline, look-ahead comparison, not a historical alarm simulation. Report paired normalized MAE on observed targets, first differences of components as stability diagnostics and coverage/runtime, not fit MAE as proof of detection. Score each mode using its own support; match identical channel signatures across modes only in a descriptive post-scoring report, never in causal fitting, calibration or score eligibility.
3. **Representations.** B1 raw; B2 Trend; B3 Seasonal; B4 Residual; B5 T/S/R; B6 raw + R; B7 raw + T/S/R. C1 raw + stats, C2 T/S/R + stats, C3 raw + T/S/R + stats. Global summaries use expanding earlier observations capped at the training boundary; local summaries use a trailing 90-day window before the token. Compute median, MAD (rolling MAD is the local version), IQR, Q10/90, actual-day slope and lag-1 autocorrelation. A signed residual z-score against the earlier 90-day residual window is an extra context feature only in decomposition-statistics arms. Per-field/channel median and robust MAD scale are fitted on training data. Missing features are carried with a separate mask; zero is only the internal masked token value.
4. **SSL control.** Fixed input slots, mask channels, shared small GRU, matched optimizer/epochs/seeds, per-field sequence blocks with warm-up, and random context deletion. Every arm predicts the same raw-channel targets from earlier inputs; train with channelwise masked Huber and evaluate masked error on common support. This isolates input representations from changes in loss. Report the raw GRU and its untrained initialization, raw annual and inferred-phase reference controls, and parameter counts. An auxiliary multi-component reconstruction loss (equal weights on individually normalized target groups, then masking/capacity/weight sensitivity) belongs to a separate architecture trial. Do not compare legacy frozen weights on a different acquisition grid as if the targets and splits matched.
5. **Standalone and hybrid scoring.** Use absolute deviation from the field's training median divided by `1.4826 × MAD` with a floor, matched either by three neighboring annual bins or by a lagged greenness stage proxy (NIR for bands, NDVI for indices). The latter stratifies on training quantiles and prior slope; it is not measured phenology. For D3 remove the field's train-fitted trend drift before taking the deviation. Require enough matched observations, without cross-farm fallback. D1 is squared raw reconstruction error. RMS aggregates the active target channels for component scores and is absent if any active channel lacks comparable history; hybrid requires all four finite scores, robustly standardizes using calibration rows and compares equal weights to four fixed one-emphasis variants. Use the empirical calibration 95th percentile and strict `>` for acquisition alarms; report the observed calibration and evaluation alarm frequencies (not ground-truth FAR). Field summary is the maximum observed score with counts, not a separately calibrated field alarm.
6. **Validation and adoption.** Inject paired, design-choice departures into NIR only in evaluation, then rederive indices. Evaluate five families, three training-scale doses, paired AP and score uplift, dose sensitivity, and deterministic 20% acquisition removal. Not a physical stress simulation. Score optional observed, provenance-bearing TVDI/CWSI/ETa matched on exact field/date; disclose shared optical scene/inputs and confounding. Optional same-date neighbor consistency uses a polygon-derived adjacency list and is descriptive. Use common support for comparisons and report counts and absent metrics. Review a multi-branch candidate only if an identical non-raw arm improves causal holdout raw reconstruction across all three seeds on a branch, with positive mean paired synthetic AP uplift versus raw on the same supported cohort for each seed. Require at least 20 fields and 100 holdout field-dates and at least 20 supported affected fields per synthetic scenario (design-choice minimums, not a significance test). Treat this as a development gate, not confirmatory selection or deployment. Smoke, retrospective-only and insufficient support cannot qualify. A follow-up must compare budget-matched early fusion with raw/trend/seasonal+residual encoders and use an independently authorized evaluation cohort.
7. **Execution.** Standalone CLI, isolated output folder, atomic work units and resumable epoch state. Keep series artifacts and checkpoints local; report config, input/split hashes, code revision, package/device details, counts and date range, runtime and seed spread. Incremental `progress.jsonl` gives epochs/loss/ETA and unit completions.

## Risks / Trade-offs

- **Irregular Landsat gaps / edge artifacts:** report unmatched support and do not read fills as observations; causal STL may have poor coverage. Similar annual positions are only a comparator to the unvalidated phase estimate.
- **Signal absorption:** lagging the estimator and masking current targets reduces shortcuts; retrospective fit and long-running causal adaptation can absorb injected signals, so measure sensitivity by family/dose rather than choosing by fit alone.
- **Frozen manifest may exclude many farms:** use it as written. `monitor/splits.py` emits a row-derived `test_fields` list; some farms in it may also occur in earlier cycles. Do not silently swap in a different field membership. If little support remains, report it and handle manifest policy in a separate change.
- **CPU/IO cost:** benchmark first, then request one decomposition method per ablation run with matching defaults. Large reports and full runs are local; smoke verifies wiring only.
