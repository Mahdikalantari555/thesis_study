# ThinkGeo: Evaluating Tool-Augmented Agents for Remote Sensing Tasks

## Summary
ThinkGeo is the first tool-augmented LLM agent benchmark for remote sensing. It evaluates ReAct-style agents over 486 tasks with 1,778 expert-annotated steps and 14 tools (ObjectDetection, ChangeDetection, Plot, OCR, etc.), covering 436 optical and 50 SAR tasks. It exposes tool-accuracy and planning gaps across GPT-4o, Claude-3, Qwen-2.5, and LLaMA-3.

## Methods / Architecture
- ReAct-style tool-augmented LLM agents
- 14 RS tools including ObjectDetection, ChangeDetection, Plot, OCR
- Expert-annotated step-level trajectory evaluation
- Multi-backbone evaluation: GPT-4o, Claude-3, Qwen-2.5, LLaMA-3

## Key quantitative results
- 486 tasks; 1,778 expert steps; 14 tools
- 436 optical + 50 SAR tasks

## Relevance to thesis
Provides an evaluation protocol for any GeoAI crop-stress agent: step-level tool use, planning correctness, and optical/SAR coverage mirror the multi-modal requirements of agricultural stress monitoring.
