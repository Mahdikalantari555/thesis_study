## Summary
AgriWorld introduces a World–Tools–Protocol framework for verifiable agricultural reasoning with code-executing LLM agents. It provides a Python environment covering geospatial parcel queries, RS time series, crop simulation, and yield/stress/disease predictors; an Agro-Reflective multi-turn execute–observe–refine agent; and AgroBench, a verifiable agricultural QA benchmark. It outperforms text-only and direct tool-use baselines.

## Methods / Architecture
- AgriWorld Python environment: geospatial parcel queries, RS time series, crop simulation, yield/stress/disease predictors
- Agro-Reflective multi-turn execute–observe–refine agent
- AgroBench: verifiable agricultural QA benchmark
- Code-executing LLM agent loop with structured tools
